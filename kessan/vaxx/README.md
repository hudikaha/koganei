# 年齢調整死亡数・予防接種費グラフ

小金井市の年齢調整死亡数と予防接種費の推移を、2010年から2025年まで表示する静的HTMLグラフです。

## 表示内容

- 赤い折れ線：年齢調整死亡数（人）
- 積み上げ棒：予防接種費（億円）
  - 新型コロナ
  - HPVワクチン
  - インフルエンザ
  - その他予防接種費
- 横方向のグリッドは、死亡数と予防接種費の目盛りを対応させています。
- 年齢調整死亡数は年ごと、予防接種費は年度ごとの集計です。

## 2025年度

`kessan/data.json` の一般会計「予防接種費」を使用しています。

- 年齢調整死亡数：1,114人
- 予防接種費総額：453,431,610円
- インフルエンザ：38,335,946円
- HPVワクチン：44,371,872円
- 新型コロナ：29,099,971円
- その他：上記以外の予防接種費

## 表示

`vaxxdeath.html` をブラウザで開いて表示します。グラフ描画にはChart.jsを使用しています。
